# 스템 4트랙 만들기

입력: `$ARGUMENTS` — 원본 파일, 곡 이름, (선택) 앞에서 잘라낼 초.

## 실행

```bash
scripts/make-stems.sh "<원본>" "<곡이름>" [자를초]
```

- 결과: `~/Desktop/stems/<곡이름>-4트랙/` — `1-드럼 / 2-베이스 / 3-기타 / 4-보컬외`.mp3 (320k · 44.1k · 스테레오)
- M1 기준 3~4분 곡 약 1분.
- Demucs 가상환경 기본값 `~/.venvs/demucs` (다르면 `DEMUCS_VENV=...`). 없으면 사용자에게 설치 여부를 먼저 묻는다(PyTorch 포함 수 GB).
- 임시 파일은 `TMPDIR`로 세션 스크래치 폴더를 지정해 두면 정리가 쉽다.

## 자를 초 정하기

- 커버/TAB 영상은 앞에 타이틀 화면이 있는 경우가 많다. 사용자가 초를 안 주면 먼저 묻는다.
- 참고: `scripts/tab-pages.py` 결과의 첫 악보 페이지 시작 시각을 보면 타이틀 길이를 알 수 있다.

## 결과 확인 (스크립트 ⑤ 출력)

- 4파일 길이가 **완전히 같아야** 한다.
- 구간 3곳 어긋남 ±2ms 이내, 상관 0.9 이상 → `싱크 OK`.
- `⚠`가 나오면 원인 확인: 보통 MP3 인코더 지연(스크립트의 `DELAY=1104`)이 달라진 경우.

## 사용자에게 알릴 것

- 커버 영상이면 `3-기타`에 원곡 기타와 커버 기타가 섞인다(분리 불가).
- 폰으로 파일 옮겨 곡 페이지 → 플레이어 탭 → 소스 "스템" → 파일 불러오기. 스템 t0는 유튜브와 따로 한 번 맞춘다.
- 음원은 저장소에 커밋하지 않는다(기기 IndexedDB에만 저장되는 설계).
