# Marigold 코드 차트 — 플레이어 탭 구현 스펙 (1단계: 유튜브 모드)

## 목표
기존 `marigold_chords.html`(첨부)에 세 번째 탭 "▶ 플레이어"를 구현한다.
유튜브 MV를 재생하면서 아래 코드 차트의 현재 마디를 실시간 하이라이트한다.

## 현재 파일 상태 (주의)
- 탭 버튼 3개는 이미 추가됨: `tabC`, `tabF`, `tabP` (tabP는 `show('P')` 호출)
- 그러나 `#viewP` 뷰와 `show()`의 'P' 분기, 플레이어 JS는 **아직 없음** — 이번에 구현할 부분
- 기존 기능 유지 필수: 컴팩트/펼침 탭, 원키↔카포2 코드 전환(`setKey`)

## 핵심 설계

### 1. 마디 계산
- 곡: Key D, ♩=107, 4/4 고정 템포
- 한 마디 길이: `BAR = 240 / 107` ≈ 2.2430초
- 현재 마디 인덱스: `n = Math.floor((t - t0) / BAR)` (t = player.getCurrentTime())
- t0 = "1마디가 시작되는 영상 시점" — 사용자 캘리브레이션으로 결정
- 재생속도를 바꿔도 getCurrentTime()은 미디어 시각 기준이므로 **보정 불필요**

### 2. 마디 → DOM 매핑
- `#viewF`(펼침 뷰)의 `.bar` 요소들이 **문서 순서 = 연주 순서**로 정확히 106개
- `document.querySelectorAll('#viewF .bar')[n]`이 현재 마디 칸
- split 마디(`.bar.split`, 앞2박/뒤2박)도 1개 마디로 카운트됨 — 그대로 두면 맞음
- 하이라이트: 현재 칸에 `.now` 클래스 (마리골드색 배경+아웃라인), 이전 칸에서 제거
- 자동 스크롤: 마디 변경 시 `scrollIntoView({block:'center'})`, 켬/끔 토글 제공 (기본 켬)

### 3. 플레이어 탭 레이아웃 (#viewP)
- 상단 sticky: 유튜브 플레이어 (16:9, 전체 폭)
- 그 아래: NOW(크게) / NEXT(작게) 코드 표시 박스 + 섹션명 + "n/106 마디"
- 컨트롤 줄 1 — 속도: [0.5x] [0.75x] [1x]
- 컨트롤 줄 2 — 캘리브레이션: [지금이 1마디 시작] [−0.1s] [+0.1s]
- 탭 'P' 활성 시 `#viewF`도 함께 표시 (차트가 플레이어 아래에서 스크롤)
- NOW/NEXT 코드명은 매 tick마다 DOM에서 읽을 것 → setKey 전환이 자동 반영됨

### 4. YouTube IFrame API
- 스크립트 lazy load: 플레이어 탭 최초 진입 시 `https://www.youtube.com/iframe_api` 주입
- playerVars: `{ playsinline: 1, rel: 0 }` — playsinline 필수 (iOS 인라인 재생)
- 영상 ID: 아이묭 마리골드 공식 MV — **구현 시 실제 ID 확인해서 상수로 입력**
- 속도 연동 양방향:
  - 페이지 버튼 → `player.setPlaybackRate(r)`
  - 유튜브 메뉴에서 변경 → `onPlaybackRateChange` 이벤트로 버튼 상태 동기화
  - 임베드는 0.25 단위 프리셋만 지원 — 0.8 요청 시 0.75로 스냅됨 (알려진 제약, UI에 0.8 버튼 넣지 말 것)
- 폴링: setInterval 100~150ms로 getCurrentTime() 읽어 마디 갱신

### 5. 캘리브레이션 UX
- [지금이 1마디 시작] 탭 → `t0 = player.getCurrentTime()` 저장
- ±0.1s 버튼으로 미세조정 (하이라이트가 늦으면 t0 감소 방향)
- localStorage 키 `mg_t0`에 저장, 로드 시 복원 (기본값 0)
- 상태 줄에 `t0=xx.xx초 · 현재 n/106 · 속도 x.x` 표시
- n < 0이면 NOW에 "대기", n ≥ 106이면 하이라이트 해제

## 엣지 케이스
- 광고: 프리롤은 t0 캘리브레이션이 본편 기준이라 무관. 미드롤 중에는 getCurrentTime이 본편 시각을 유지하는지 확인, 이상 시 일시정지 상태(`getPlayerState !== 1`)에서 폴링 스킵
- 곡 후반 싱크 드리프트: 고정 템포 스튜디오 음원이라 없을 것으로 예상. 실측에서 밀리면 BAR 미세조정 입력 추가 검토
- 사용자가 차트를 수동 스크롤 중일 때 자동 스크롤과 충돌 → 자동 스크롤 토글로 해결 (기본 구현), 여유 되면 수동 스크롤 감지 후 3초 일시정지

## 테스트 체크리스트 (모바일 Safari 우선)
1. 플레이어 탭 진입 → 영상 로드, 인라인 재생 (전체화면 강제 전환 없어야 함)
2. 캘리브레이션 후 코드 하이라이트가 귀로 듣는 코드 전환과 일치 (벌스·후렴·브릿지 각 1회 확인)
3. 0.75x 변경 → 하이라이트 속도 자동 추종, 유튜브 메뉴에서 1x 복귀 → 버튼 동기화
4. setKey(카포2) 전환 → NOW/NEXT와 차트가 함께 C형 코드로 표시
5. 새로고침 후 t0 유지 (localStorage)
6. 홈 화면 추가(PWA-lite) 상태에서 1~5 재확인
